How the Stack Works

  1. Push: Save a previous text state.
  2. Pop: Remove the most recent saved state.
  3. Undo: Move backward to a previous state.
  4. Redo: Restore a state that was undone.

LIFO: Last In, First Out. The latest saved state is the first state retrieved.
